# Website

For a company site, landing page or blog with no user accounts: light, fast pages with top accessibility, tuned for search engines and AI agents.

An ultra-lightweight, AI-native framework for generating high-performance landing pages.

Every page is hand-designed static HTML (MPA / SSG), with JavaScript only where a page asks for it. Agents start at [`prompts/00-start-here.md`](prompts/00-start-here.md). Nothing is published until `bun run verify` ends in `VERIFY PASSED`.
