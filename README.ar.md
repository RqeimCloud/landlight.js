# موقع ويب

لموقع تعريفي أو صفحة هبوط أو مدونة بلا حسابات للمستخدمين: صفحات خفيفة وسريعة بأعلى وصولية، ومحسّنة لمحركات البحث ولوكلاء الذكاء الاصطناعي.

كل صفحة HTML ثابتة مصمّمة بعناية، وJavaScript فقط حيث تحتاجه الصفحة. يبدأ الوكلاء من [`prompts/00-start-here.md`](prompts/00-start-here.md)، ولا يُنشر شيء حتى ينتهي `bun run verify` بـ`VERIFY PASSED`. مفتوح المصدر برخصة [MIT](LICENSE).
