# 2. صمّم الموقع وابنِه

**لا شكل مفروض.** كل ما في هذا الملف وفي [`design-options.md`](design-options.md) خيارات جاهزة تبدأ منها، فعدّل عليها أو اخلطها أو تجاوزها. البوابة لا تحكم على شكل التصميم، بل على النتيجة: الدرجات، وإمكانية الوصول، وأن تكون كل لغة صفحة حقيقية. أي تصميم يحقق ذلك مقبول، مهما كان جريئًا.

## ابدأ بقرار، لا بقالب

اكتب لنفسك سطرًا واحدًا: «أقرأ هذا الطلب على أنه: <نوع الصفحة> لـ<الجمهور>، بلغة بصرية <الإحساس>، تميل إلى <الاتجاه>».

ثم اختر اتجاهًا من [`design-options.md`](design-options.md) أو ابتكر اتجاهك. المؤشرات الثلاثة هناك (الجرأة والحركة والكثافة) أداة تفكير، لا قاعدة.

عرّف نظام التصميم في `@theme` داخل `src/app.css`: الألوان والخطوط ومقياس الأحجام. هكذا تبقى الصفحات متسقة مهما كان الاتجاه. واجعل `brand.theme` في `site.config.json` مساويًا للون الهوية.

## ما يجعل الموقع يبدو آليًا

تجنّب هذه العلامات ما لم تقصدها لسبب واضح:

- تدرّج بنفسجي أو أزرق على خلفية داكنة، وعنوان في الوسط فوق شبكة ضبابية.
- ثلاث بطاقات متساوية بأيقونة وسطرين، أول شيء بعد الهيرو.
- زجاج ضبابي وتوهج في كل مكان.
- حركة دائمة لا تشرح شيئًا.
- عبارات فارغة: «حلول مبتكرة»، «نرتقي بأعمالك».
- مكون منسوخ من مكتبة دون أن يُعدَّل على هويتك.

## بنية تحوّل الزائر

هذه خيارات مجرَّبة، ورتّبها كما يناسب الجمهور. كل قسم يجيب عن سؤال واحد: ما هذا؟ لماذا أحتاجه؟ كيف يعمل؟ ما الدليل؟ كم يكلف؟ كيف أبدأ؟

- أول شاشة على عرض 390px تقول ماذا تقدم ولمن، وفيها الإجراء الأساسي.
- الإجراء الأساسي يتكرر عند نقاط القرار، ويوضح ما يحدث بعد الضغط.
- الدليل حقيقي من صاحب الطلب. لا خصم وهمي، ولا ندرة مصطنعة.
- السعر أو طبيعته، والمنطقة، والمواعيد، تُكتب نصًا.

## الصفحة

```html
<!doctype html>
<html lang="{{lang}}" dir="{{dir}}">
<head>
  <meta charset="UTF-8" />
  <meta name="viewport" content="width=device-width, initial-scale=1.0" />
  <title>{{t:services.title}}</title>
  <meta name="description" content="{{t:services.description}}" />
  <link rel="stylesheet" href="/app.css" />
</head>
<body>
  <include src="src/components/header.html"></include>
  <main id="main"><h1>{{t:services.heading}}</h1></main>
  <include src="src/components/footer.html"></include>
  <script type="module" src="/app.js"></script>
</body>
</html>
```

**كل الصفحات بكل اللغات تتولد من ملف واحد.** تكتب `src/views/services.html` مرة، ونصوصه في `src/locales/ar.json` و`src/locales/en.json`:

```json
{ "services": { "title": "زراعة الأسنان في الرياض | عيادة النور", "description": "…", "heading": "…" } }
```

فيخرج البناء `/services` بالعربية و`/en/services` بالإنجليزية، صفحتين HTML حقيقيتين تفهرسهما محركات البحث.

- `{{t:مفتاح}}` نص المفتاح بلغة الصفحة، ويقبل HTML مثل `<strong>`. ويصح داخل السمات (`alt` و`aria-label`) وداخل JSON-LD، ويُهرَّب تلقائيًا.
- `{{href:contact}}` رابط الصفحة بلغة الصفحة نفسها، و`{{href:index}}` للرئيسية.
- `{{locale:en}}` الصفحة نفسها بالإنجليزية، لزر تبديل اللغة. في الهيدر الحالي: `{{locale:{{t:language.other}}}}`.
- `{{lang}}` و`{{dir}}` لوسم `<html>`.
- `<include>` يبدأ من جذر المشروع ولا يدعم `<slot>`. والمكوّنات تستعمل المفاتيح نفسها، فنسخة واحدة تخدم كل اللغات.
- `src/pages/` يتولد ويُحذف مع كل بناء، فلا تكتب فيه.
- اكتب كل لغة بصياغة أهلها: طول الجملة والنبرة والأمثلة تختلف، والمفتاح واحد.
- رابط التخطي إلى `#main`، والرابطان إلى صفحتي الخصوصية والشروط، يبقيان في كل صفحة.

## أي فكرة، بدرجة 100

الهدف 100، والنشر يكفيه الأخضر. الإبداع لا يتعارض مع السرعة إذا بُني بالطريقة الصحيحة، والجدول يبيّن كيف:

| تريد | اصنعه هكذا |
|---|---|
| فيديو يملأ الهيرو | صورة WebP بصفتها `poster` وهي أكبر عنصر، ثم `<video preload="none" muted playsinline>` يبدأ من جزيرة بعد التحميل |
| مشهد ثلاثي الأبعاد أو WebGL | صورة ثابتة له في HTML، وجزيرة تستبدلها حين تظهر في الشاشة، ولا يُحمَّل في الشاشة الأولى |
| حركة غنية بالتمرير | CSS `animation-timeline: view()` أولًا، ثم GSAP أو motion في جزيرة للأقسام التي تحت الشاشة الأولى |
| خطوط عدة وأوزان كثيرة | خط الشاشة الأولى يُحمّل مسبقًا (preload)، والبقية `font-display: swap`، وكل الملفات من `src/public/fonts/` |
| معرض صور كبير | `loading="lazy"` و`srcset` لكل صورة، والسلايدر بـ`scroll-snap` أو Embla في جزيرة |
| خريطة، دردشة، تتبّع | تُحمَّل عند الطلب، أو بجزيرة `data-load="idle"` |
| تأثيرات بين الصفحات | `view-transition-name` على العنصر نفسه في الصفحتين |

القاعدة الوحيدة خلف الجدول: **أكبر عنصر في الشاشة الأولى يظهر من HTML وCSS وحدهما.** لا تضع عليه `opacity: 0`، ولا تجعله خلفية CSS، ولا تضع عليه `loading="lazy"`. وإن كان صورة فأعطه `fetchpriority="high"`.

## التفاعل: أول درجة تكفي

1. **المنصة:** CSS، و`popover`، و`<details>`، و`<dialog>`.
2. **Alpine:** ضع `x-data` في الصفحة، فيُحمَّل Alpine من حزمة المشروع نفسه في تلك الصفحة وحدها.
3. **جزيرة:** ثبّت المكتبة، وأنشئ `src/islands/<الاسم>.js`، ثم ضع `data-island="<الاسم>"` على العنصر:

   ```js
   import EmblaCarousel from 'embla-carousel'
   export default element => EmblaCarousel(element, { direction: document.dir })
   ```

   تعمل الجزيرة حين يقترب العنصر من الشاشة، و`data-load="idle"` يشغلها بعد هدوء الصفحة. والمحتوى يكون كاملًا في HTML قبل أن تعمل.

اختيار المكتبات في [`libraries.md`](libraries.md).

## الخطوط

من المشروع نفسه، ولا تُحمّل من Google Fonts. ملفات الخط تجدها بعد التثبيت في `node_modules/@fontsource/<الاسم>/files/`:

```bash
npm install --no-save @fontsource/tajawal
mkdir -p src/public/fonts
cp node_modules/@fontsource/tajawal/files/tajawal-arabic-{400,700}-normal.woff2 src/public/fonts/
```

```css
@font-face { font-family: "Tajawal"; src: url("/fonts/tajawal-arabic-400-normal.woff2") format("woff2"); font-weight: 400; font-display: swap; }
@theme { --font-sans: "Tajawal", system-ui, sans-serif; }
```

الأرقام اللاتينية في ملف `latin` منفصل، فانسخه أيضًا إن كانت الصفحة تعرضها.

## الصور: WebP فقط

ضع كل الأصول في `media/` بأي صيغة (JPG أو PNG أو AVIF أو TIFF أو GIF أو SVG)، ثم شغّل `npm run assets`. يحوّل الأمر الصور إلى WebP بثلاثة عروض بأعلى ضغط ممكن، ويحسّن SVG، ويطبع وسم `<img>` جاهزًا لكل صورة. البوابة ترفض أي صورة غير WebP أو SVG، ما عدا الأيقونات وصورة المشاركة، فهذه تبقى PNG لأن بعض المنصات لا تقرأ WebP لها.

اضبط `sizes` على عرض الصورة الفعلي في التصميم، مثل `(min-width: 768px) 50vw, 100vw`، لا `100vw` دائمًا.

## CSS لا ينكسر

- `flex-wrap` على كل صف قد يطول، و`min-width: 0` على عناصر flex/grid التي فيها نص.
- `aspect-ratio` و`object-fit` للوسائط. والنص فوق صورة يحتاج طبقة تضمن التباين.
- `min-height` بدل `height` الثابت، و`100dvh` بدل `100vh`.
- hover داخل `@media (hover: hover)`، والحقول 16px فأكبر، وأهداف اللمس 44px.
- `overscroll-behavior: contain` لكل منطقة تمرير داخلية.
- الحركة الزخرفية داخل `@media (prefers-reduced-motion: no-preference)`، وتحريك `transform` و`opacity` فقط.

## العربية والاتجاه

- خصائص منطقية: `ms-*` و`pe-*` و`text-start` و`start-*`. لا `ml-*` ولا `text-left`.
- الأيقونات ذات الاتجاه تُقلب بـ`rtl:-scale-x-100`، والشعارات لا تُقلب.
- في العربية: `letter-spacing` صفر، ولا `uppercase`، ولا مائل، ولا `word-break: break-all`.
- ارتفاع السطر نحو 1.8 للنص و1.35 للعناوين، والنص الثانوي بلون صلب لا بـ`opacity`.
- نظام أرقام واحد في الصفحة، والهاتف والإيميل داخل `dir="ltr"`.

## الوصول

- `h1` واحد، والعناوين بالتسلسل دون قفز. التباين 4.5:1 للنص العادي.
- كل حقل له `<label>`. الخطأ يُكتب نصًا، وحالات الإرسال ظاهرة.
- الروابط وسط النص لها خط سفلي، و`:focus-visible` يبقى ظاهرًا.
- `alt` يصف الصورة بلغة الصفحة، و`alt=""` للزخرفة فقط.

## التواصل والخريطة

الموقع ثابت بلا خادم، فاسأل صاحب الطلب أين تصل الرسائل: واتساب `https://wa.me/...`، أو `mailto:`، أو `tel:`، أو نموذج يرسل إلى رابط حقيقي يعطيك إياه.

ولنشاط له مقر، اعرض الخريطة دون أن تحمّلها مسبقًا:

```html
<address class="not-italic">العنوان نصًا</address>
<a href="https://www.google.com/maps/search/?api=1&query=24.7136,46.6753">افتح الموقع في الخرائط</a>
<details>
  <summary>عرض الخريطة</summary>
  <iframe title="الموقع على الخريطة" loading="lazy" width="600" height="400" class="w-full"
    src="https://maps.google.com/maps?q=24.7136,46.6753&z=16&output=embed"></iframe>
</details>
```
