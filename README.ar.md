# موقع ويب

لموقع تعريفي أو صفحة هبوط أو مدونة بلا حسابات للمستخدمين: صفحات خفيفة وسريعة بأعلى وصولية، ومحسّنة لمحركات البحث ولوكلاء الذكاء الاصطناعي.

كل صفحة HTML ثابتة مصمّمة بعناية، وJavaScript فقط حيث تحتاجه الصفحة. يبدأ الوكلاء من [`prompts/00-start-here.md`](prompts/00-start-here.md)، و`bun run verify` فحص يُشغَّل مرة قبل النشر، لا شرط له. مفتوح المصدر برخصة [MIT](LICENSE).

الصفحات المشحونة و`src/app.css` **هيكل محايد**: بنية ونصوص وإمكانية وصول فقط، بلا هوية لونية ولا خط عرض. التصميم يُشتق من الطلب؛ وإبقاء الهيكل كما هو يعني موقعًا بلا هوية.
