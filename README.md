# Website

For a company site, landing page or blog with no user accounts: light, fast pages with top accessibility, tuned for search engines and AI agents.

An ultra-lightweight, AI-native framework for generating high-performance landing pages.

Every page is hand-designed static HTML (MPA / SSG), with JavaScript only where a page asks for it. Agents start at [`prompts/00-start-here.md`](prompts/00-start-here.md). `bun run verify` is a check run once before publishing, not a condition for it.

The pages and `src/app.css` that ship are a **neutral skeleton** — structure, words and accessibility only, no brand palette, no display face. The design comes from the request; keeping the skeleton as it is means shipping a site with no identity.
