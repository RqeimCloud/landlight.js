Put the logo here as `logo.svg` (or `.png`, `.webp`, `.jpg`) and every image as `<name>.jpg`, `.png`, `.webp`, `.avif`, `.tiff`, `.gif` or `.svg`, with a lowercase name. Then run `npm run assets`: photos become WebP in three widths, SVGs are optimized, and the `<img>` tag to paste is printed for each one.

The site serves WebP and SVG only. The icons and the share image stay PNG, because some platforms do not read WebP for them.
