# 1. اجمع الحقائق

هذه الخطوة للحقائق فقط، والتصميم في الخطوة التالية.

## المطلوب من صاحب الطلب

اجمع هذه القائمة قبل كتابة أي صفحة. ما كان ناقصًا فاسأل عنه دفعة واحدة:

| البند | مثال |
|---|---|
| اسم النشاط بكل لغة كما يكتبه صاحبه | عيادة النور / Alnoor Clinic |
| الدومين النهائي | `https://alnoor.sa` |
| لغات الموقع، والأولى هي الأساسية | العربية ثم الإنجليزية |
| ماذا يقدم، ولمن، وفي أي مدينة أو بلد | طب أسنان، الأسر، الرياض |
| الإجراء الوحيد المطلوب من الزائر | حجز موعد عبر واتساب |
| البريد والهاتف وحسابات التواصل | |
| الشعار (SVG، أو PNG مربع 512px فأكبر) وألوان الهوية | |
| هل له مقر يزوره الناس؟ العنوان والإحداثيات وساعات العمل | |
| هل يوجد تتبّع (Analytics/إعلانات)؟ ومعرّفه | |
| ماذا يحدث لبيانات الزائر (نموذج؟ أين تصل؟) | |

## املأ `site.config.json`

```json
{
  "url": "https://alnoor.sa",
  "email": "info@alnoor.sa",
  "phone": "+966XXXXXXXXX",
  "sameAs": ["https://x.com/alnoor"],
  "brand": { "theme": "#0E1B4D", "background": "#ffffff" },
  "locales": {
    "ar": { "og": "ar_SA", "name": "عيادة النور", "description": "جملة واحدة واضحة تصف النشاط." },
    "en": { "og": "en_US", "name": "Alnoor Clinic", "description": "One clear sentence about the business." }
  },
  "business": {
    "type": "Dentist",
    "address": { "streetAddress": "...", "addressLocality": "الرياض", "addressRegion": "الرياض", "postalCode": "...", "addressCountry": "SA" },
    "geo": { "latitude": 24.7136, "longitude": 46.6753 },
    "openingHours": ["Su-Th 09:00-21:00"],
    "priceRange": "$$"
  }
}
```

- `url` بلا `/` في آخره، وهو الدومين النهائي لا رابط تجربة.
- **أول لغة في `locales` هي الأساسية** وتظهر في جذر الموقع، وغيرها تحت `/en/` مثلًا. لموقع بلغة واحدة احذف الباقي من `locales` وملفاتها من `src/locales/`. لإضافة لغة أضفها هنا وأنشئ `src/locales/<لغة>.json` بالمفاتيح نفسها كلها، فتتولد صفحاتها وحدها.
- `brand.theme` لون شريط المتصفح وتطبيق PWA، و`brand.background` خلفية الأيقونات. ألوان الموقع نفسها تكتبها في `src/app.css` في الخطوة التالية. لا بد من الصيغة `#rrggbb`.
- `business` للنشاط الذي له مقر حقيقي، ويأخذ `type` أدق نوع من schema.org (`Store`، `Restaurant`، `Dentist`…). لغير ذلك اتركه `null`.
- `sameAs` روابط حسابات حقيقية فقط، أو `[]`.

## الشعار

ضع الشعار في `media/logo.svg` (أو `logo.png` مربعًا 512px فأكبر)، ثم:

```bash
npm run assets
```

يولّد الأمر كل المقاسات: favicon بـ16 و32 و48، وApple 180، و192 و512، وmaskable، وصورة المشاركة 1200×630، وشعار الهيدر. كل ما في `media/` غيره يتحول إلى صور WebP بثلاثة عروض، ويطبع الأمر وسم `<img>` جاهزًا لكل صورة لتنسخه في صفحتك.

انظر للأيقونة `src/public/favicon-32.png` بعد التوليد: إن كان الشعار غير مقروء فاطلب نسخة مبسطة منه. وإن توفرت صورة مشاركة مصممة بعنوان واضح فضعها مكان `src/public/og.png` بالأبعاد نفسها بعد آخر تشغيل للأمر.

## اكتمال هذه الخطوة

- [ ] لا يبقى `example.com` في `site.config.json`، و`name` لكل لغة هو اسم النشاط.
- [ ] شغّلت `npm run assets` وراجعت النتيجة.
